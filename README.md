## ゲームの概要
- 作品名：Minesweeper3D
- バージョン：1.00
- 制作者：とぅな
___
- ジャンル：パズル
- 作品概要：従来のマインスイーパーを3Dに拡張したゲームになります。より高度な思考を巡らせてプレイすることができるようになっています。
- 推定プレイ時間：10分~4時間 (途中で保存できる機能があります。)
___
## web公開リンク
UnityRoomにて公開しています。

webGLのため一部機能に制限があります。

https://unityroom.com/games/mine-sweeper-3d
___
## 操作説明
### 基本操作
- 決定：左クリック
### マインスイーパープレイ中の2D部
- マスの開示：左クリック
- 旗の設置/解除：右クリック
- レイヤーの変更：スクロール
### マインスイーパープレイ中の3D部
- 視点の回転：左クリック
- 視点の移動：右クリック
- 視点の拡大/縮小：スクロール
